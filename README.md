# expense-tracker

Personal expense tracker web app with budget summaries and local persistence.

## Quick start in GitHub Codespaces

1. Open the repository in GitHub Codespaces.
2. Wait for the container to finish installing dependencies.
3. The app should start automatically on port 5173.
4. Open the forwarded port in the browser.

## Local development

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```

## Features

- Dashboard with total balance
- Income and expense tracking
- Monthly budget control
- Category filtering
- Local storage persistence
- Responsive layout
